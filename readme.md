# Figure Skating 外部仕様・利用ガイド

作成日：2026-11-17。提供されたweb.zipの実装を基準とする。
対象はWebアプリ全体。テストプログラム自体の仕様書ではない。

## 1. 用途

フィギュアスケートの大会・選手・演技・実行要素を検索し、採点表と関連する公式資料や動画を参照するWebシステム。
自然文からSQLを生成するText-to-SQLを利用し、登録済み競技データを検索する。
競技結果の収集・登録、マスタ整備、採点の再計算を行う管理システムではない。

公開URL：https://figure.tasamu.org/

## 2. 基本的な使い方

| 操作 | 内容 |
|---|---|
| 大会から探す | 左の年度→大会→種目を展開し、種目をクリック |
| 演技を見る | 一覧の演技日や得点等のリンクから採点表へ移動 |
| 選手の履歴を見る | 選手名をクリックして、その選手の演技一覧を表示 |
| 条件を文章で指定 | 演技検索へ入力して検索ボタンを押す |
| 要素から探す | 実行エレメント検索で名前・種目・点数などを指定 |
| マスタを見る | エレメント、選手、カテゴリ等の一覧・検索を開く |
| 説明を読む | プロトコルの読み方、エレメント説明へのリンクを開く |

一覧の見出しの並べ替えリンクは、クリックで昇順・再クリックで降順となる。
左ツリーと本文の境界はドラッグで幅を変更できる。
画面上のリンクが別画面・別タブを開く場合がある。

## 3. 大会・種目別の順位一覧

各選手の登録済みセグメントを横並びで表示する。SP/FSやRD/FDの得点・各順位を確認できる。
一覧の総合順位は、登録されたセグメント得点の合計から計算する。
2つ以上のセグメントがあり、その大会・種目に存在する全セグメントで順位が正数の場合に完了扱いとする。
未完了選手は総合順位を付けず、完了選手の後ろに表示する。
同じ合計点は同順位で、公式のタイブレーク規定は再現しない。
したがって、表示した総合順位が公式最終順位と一致する保証はない。

## 4. 演技検索（自然文）

入力例：

- 日本女子のスコアが高い演技
- 羽生結弦の最高得点の演技
- 男子の4回転ジャンプを含み、減点のない演技
- 3回転のコンビネーションを含む演技

AIが入力を解釈し、登録済みデータから演技を取得する。
確認質問は行わず、必要な解釈・注釈を結果先頭に表示する。
標準は最大20件。「ベスト」「最高得点」等の単一演技指定は原則1件。明示件数も最大20件。
並び順の指定がなければ原則として演技日の新しい順。
日本語の選手名をローマ字候補に変換し、実際の選手登録と照合する。
複数登録が一致した場合は、それらをまとめて検索対象にできる。
結果の説明文は検索条件の意図であり、正しい条件になったことの保証ではない。

検索時はボタンが「検索中…」となり、同じフォームの二重送信を防ぐ。
AIの解釈、表記揺れ、登録漏れ等で検索漏れや意図と違う結果が発生する場合がある。
同じ質問の再表示は一定時間キャッシュを使用するが、結果データはDBへ再問い合わせする。

## 5. 採点表

選手名・国・大会・種目・セグメント・演技日・順位・得点と、要素別・構成点別の評価を表示する。
最終GOEの点数と、各審判のGOE段階評価は別項目として扱う。
実行した要素名は元データのeles.nameをそのまま表示し、分解情報から再合成しない。
元のISUプロトコルPDFへのリンク、大会・種目一覧へのリンクを提供する。
記録のない係数・減点内訳などを推定して補わない。
データの欠損・年代差・誤登録は表示結果へ影響する。

## 6. YouTube動画

1. 該当演技に有効な登録済み動画があれば優先する。
2. 登録がなく、自動検索が有効ならYouTube検索とAI候補照合を行う。
3. 最大4件を1つの再生枠で左右に切り替える。

AIは動画のタイトル・チャンネル名等から対応を判断し、映像自体は視聴しない。
候補が不適切または不確かなら除外する。必ず候補を表示するものではない。
削除済み、非公開、地域制限、埋め込み制限などで再生できない場合がある。
YouTubeサイト上での検索リンクも利用できる。
自動検索を無効にしても、有効な登録済み動画は表示する。

## 7. マスタ検索

| 対象 | 条件・表示 |
|---|---|
| エレメント | 名前、ジャンル、レベル／回転数、アイスダンス区分。100件単位でページ移動 |
| 選手 | 名前、カテゴリ、国。最大100件 |
| カテゴリ | 登録済みカテゴリの一覧 |
| ジャンル | 登録済みジャンルの一覧 |
| コンポーネント | 登録済み構成点項目の一覧 |
| セグメント | 登録値とシステムで統一した表示名の一覧 |

名前は部分一致。マスタ検索の%や_はSQLワイルドカードではなく通常文字として扱う。
ジャンプのレベル／回転数条件は、通常のジャンプコードでは先頭数字から回転数を判定する。
マスタは現時点で全情報を網羅しておらず、すべてを網羅する予定を意味しない。
選手一覧から演技履歴や確認済みの公式選手情報へ移動できる。
公式プロフィールはリンクとして参照し、写真・紹介文を転載する機能ではない。

## 8. 実行エレメント検索

マスタではなく、実際の演技に記録されたelesを検索する。

| 分類 | 条件 |
|---|---|
| 名前 | 実行要素名の部分一致 |
| 競技条件 | カテゴリ、ジャンル、セグメント、年度 |
| 点数 | 基礎点・GOE・要素得点の下限／上限 |
| フラグ | 後半実行、エッジエラー、無効の有無 |

点数は通常単位で小数第2位まで入力する。下限は上限以下とする。
最大100件を表示し、超える場合は条件を絞る案内を出す。
日付や採点表リンクから該当演技へ移動できる。
ジャンルの一部はコードを判定して補正するが、すべての歴史的要素を判別するものではない。

## 9. 年度・言語・表示上の約束

- 年度は4月から翌年3月。カレンダー年とは区別する。
- ブラウザのAccept-Languageから日本語／英語を選択する。所在地では判定しない。
- セグメントは10=SP、20=FS、30=RD（旧SD）、40=FDと表示。歴史的CD/ODは区別する。
- 表示名の統一によって、過去の競技ルールを現行ルールに置き換えるわけではない。
- DBの名前・説明文は自動翻訳されず、英語画面にも登録言語が残る場合がある。


## 12. 制約と運用範囲

本体DBへの更新機能はない。大会追加・修正・マスタ整備は別途実施する。
収録期間・大会数・演技の有無は配置したDBに依存する。
API通信障害や利用上限に達すると、AI検索・動画検索が利用できない場合がある。
AI・YouTube等の外部サービス利用には、それぞれの利用枠・費用・規約が適用される。
停止中はWebへアクセスしても利用できない。開始・停止、AP/DB更新はmente.mdを参照。
